## 0. v0.3.0 变更：卫星影像 + 片状阴影粗判

| # | 能力 | 说明 |
|---|---|---|
| 1 | 拉卫星瓦片 | 后台 `fetch` 高德卫星瓦片（`webst0X.is.autonavi.com/appmaptile?style=6`），本地缓存进 IndexedDB 的 `tiles`。库里是 WGS84，瓦片是 GCJ-02 对齐，取瓦片前先转坐标；`manifest` 增加了 `https://*.autonavi.com/*` 权限 |
| 2 | 单小区影像 | 点开小区详情 → z18 三瓦片（约 380 m 见方）拼图 + 指标 + 判定按钮 |
| 3 | 大圆扫描 | 「发现」页 → 扫描搜索范围；不低于 z16（再粗就看不出楼影），瓦片超上限时缩小覆盖半径并在界面上写明"实际覆盖半径" |
| 4 | 片状阴影检测 | 分绿/水 → **Otsu 二值化** → **开运算（5 m）**抹掉细影 → 连通域 → 只留"片状"（面积 ≥150 ㎡、填充 ≥0.35、长宽比 ≤8，**不设面积上限**）→ 打分 |
| 5 | 叠加显示 | 命中块涂半透明红 + **1 px 亮红描边**（暗阴影上也能看出标了哪） |
| 6 | 人工校对 | 每块可点「像小区 / 不像 / 忽略」，判定存本机；高分的可「加为小区」，表单自动带坐标 |

**这一版踩过的两个坑（已修）**

1. 最初给片状阴影设了面积上限（9000 ㎡）和填充率下限（0.45），结果**最明显的那一大片方形阴影是一整块 5.8 万 ㎡、填充率 0.27 的连通域，直接被丢掉**，反而标出了一堆碎影——正好搞反。现在只做下限，面积在打分时封顶。
2. 航拍阴影偏蓝，被旧的水面判据（`b > r+10 && b > g+2`）误判成水面，触发水面惩罚把整图的分数打到 22 分。现在要求明显偏青蓝（`b-g ≥ 4`、`b-r ≥ 12`、`exg ≤ 2`）。

**已知会错（人工校对时重点看）**

- 道路、广场、深色屋面（尤其厂房）会被当成片状阴影；公园树冠堆叠也可能给高分。
- 整体偏暗/欠曝的截图（如手机翻拍）阈值会偏，Otsu 会把大片暗地都吃进去；正射瓦片（z16–z18）表现正常。
- 评分只用于排序，不是判决；参数都在 `extension/app/lib/imagery.js` 的 `DEFAULTS`（`openRadiusM`、`minPatchAreaM2`、`minFill`、`maxAspect`）。

**验收**：`/tmp/xat-test/samples2/` 下的「枫叶新都市」「东辛庄」两张标红图你确认过：东辛庄是平房 + 安置楼混杂，标出来的是楼房的影子，符合预期。

## 2. 文件结构

```
extension/app/                    ← 可加载根目录（也是 zip 的内容）
├── manifest.json                 权限：storage + *.amap.com；两个 content script（MAIN / ISOLATED）
├── background.js                 IndexedDB（settings/communities/logs/diag）+ RPC + 打开标签
├── lib/
│   ├── geo.js                    WGS84↔GCJ-02、haversine、最小外接圆、圆上取点、分档色
│   └── logger.js                 console + 落库；捕获 error / unhandledrejection
├── content/
│   ├── map-hook.js               MAIN world：拦截 window.AMap → 包 AMap.Map → 投影服务
│   ├── ui.js                     ISOLATED：Shadow DOM 侧栏 + canvas 绘制 + 交互
│   └── ui.css                    仅在 Shadow DOM 内生效（不会污染高德页面）
├── options/                      设置与诊断页（状态自检 / 日志 / 数据 / 版本说明）
├── popup/                        弹窗：状态 + 打开高德 + 进诊断页
└── README-安装说明.txt           给 Windows 用户的安装步骤
```

## 3. 关键设计决定

| 决定 | 原因 |
|---|---|
| **Shadow DOM 承载全部 UI** | 高德的 CSS 不会影响我们，我们的 CSS 也不会污染高德（第一版曾把 `ui.css` 声明进 `content_scripts.css`，那是注入到页面 DOM 的，会改到高德的按钮样式，已改掉） |
| **canvas 用 `pointer-events:none`，命中检测自己做** | 这样地图的拖动、缩放完全不受影响；只在离点 11px 内且位移 <6px 时才算"点击小区" |
| **投影请求走 postMessage，UI 只传 GCJ-02 坐标** | 坐标转换留在 UI 侧（有 `geo.js`），MAIN world 只做纯投影，避免两处各写一份转换 |
| **兜底三层：拦截赋值 → 轮询补挂（60s）→ 原型方法兜底网** | 第一次实测出现过"patched 但没实例"，加兜底避免偶发失败 |
| **数据全在 background 的 IndexedDB** | 内容脚本的 IndexedDB 属于 amap.com 的 origin，清缓存就没了 |
