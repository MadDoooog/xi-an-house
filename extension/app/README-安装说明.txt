西接通勤 · 浏览器扩展 v0.2.0
=================================

这个版本做了什么
----------------
1. 只在高德地图网页（*.amap.com）上生效，其他网站完全不注入。
2. 默认是干净状态：不再预置样例小区和假目的地，第一次用就是空的。
3. 侧边栏默认折叠：右边缘只留一个竖着的「找房」小抽屉，点一下才展开。
   展开后的上下留白可在「筛选条件 → 侧栏位置」里用两个滑杆调整（默认 上 72 / 下 24），
   用来躲开高德自带的图层、卫星、测距工具条和底部版权条。
4. 在高德地图任意位置点右键，菜单里会多一项「复制地址」（是加在高德自己菜单里的，
   同时把地址文字 + WGS84 坐标写进剪贴板）。把复制到的内容粘贴到插件的地址框，
   会自动带出坐标，并画出搜索范围。
5. 侧边栏叠加：搜索范围圆、目的地 pin（①②③）、小区点（按最长通勤分档上色）。
6. 小区可以手动录入 / 编辑 / 删除；也可以在「设置与诊断」里导入 JSON / GeoJSON
   （支持后端导出的官方数据），同名且 200 米内自动去重。
7. 点详情里的「去高德算」，会用深链在新标签打开高德的路线规划，由高德自己算真实通勤。
8. 所有关键步骤都有日志，出问题可以一键复制诊断信息发给开发者。

本版还没有的（下一步）
----------------------
- 通勤时长目前是「直线估算」，数字前带 ~。真实时长要等下一版从高德结果页读回。
- 预算 / 面积筛选滑块、自动发现小区、卫星影像与边界绘制。

注意：右键「复制地址」里的地址文字来自高德自己的地理编码接口。
未登录高德时，高德不返回地址文字，此时只复制坐标（坐标本身足够用，可手动补名字）。


安装步骤（Windows）
-------------------
1. 把压缩包解压到 D 盘根目录，得到：
      D:\xian-commute-ext\manifest.json
   （注意：文件夹里直接就是 manifest.json，不要再套一层目录）

2. 打开 Chrome 或 Edge，地址栏输入：
      chrome://extensions      （Edge 是 edge://extensions）

3. 打开右上角「开发者模式」开关。

4. 点「加载已解压的扩展程序」，选择 D:\xian-commute-ext 这个文件夹。

5. 打开（或刷新） https://www.amap.com/ ，页面右边缘应出现一个竖着的「找房」抽屉，
   左下角出现「西接通勤 · 已连接地图」。

   如果没出现：
   - 先刷新一次高德页面（扩展刚装好时旧页面不会自动注入）
   - 点浏览器工具栏的扩展图标 → 看「挂钩状态」
   - 还是不行：扩展图标 → 设置与诊断 → 点「复制诊断信息」，把内容发我


怎么用
------
1. 点右边缘的「找房」抽屉展开侧栏 → 点顶部那行「还没设目的地」。
2. 在高德地图上对你关心的地方（公司/家/学校）点右键 →「复制地址」。
3. 在「目的地」里点「＋ 添加目的地」，把复制到的内容粘进输入框（会自动定位）；
   只有地名没坐标时点「解析」。最多 5 个目的地，每个可单独选驾车/公交/步行。
4. 拖「半径」滑杆调搜索范围；拖「顶部/底部留白」把侧栏挪开高德工具条。
5. 点「保存」。侧栏顶部那行会变成「N 个目的地 · 半径 · 预算」。
6. 小区数据：点列表底部的「＋ 添加小区」手动录（名称框里粘贴右键复制的内容即可带坐标），
   或去「设置与诊断 → 数据 → 导入 JSON / GeoJSON」。
7. 点列表里的小区，面板变宽成两列：左边继续可选其他小区，右边是详情。
   详情底部「编辑小区」可以改价格、面积、产权等。
8. 地图上的点可以直接点，按 Esc 收起详情；点侧栏左上的「›」再收起侧栏。


数据在哪
--------
只存在浏览器的本地 IndexedDB（扩展自己的域），不上传任何服务器。
「设置与诊断」页可以导出全部数据、导出日志、清空小区库。

升级说明
--------
从 0.1.0 升到 0.2.0 时，扩展会自动删掉 0.1.0 预置的 12 条虚构样例和 3 个假目的地，
你自己录入的数据不受影响。
