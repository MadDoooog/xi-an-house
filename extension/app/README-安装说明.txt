西接通勤 · 浏览器扩展 v0.1.0
=================================

这个版本做了什么
----------------
1. 只在高德地图网页（*.amap.com）上生效，其他网站完全不注入。
2. 在高德地图上叠加：你的搜索范围圆、目的地 pin（①②③）、小区点（按最长通勤分档上色）。
3. 右侧侧边栏：条件摘要 / 通勤刻度尺 / 小区列表 / 两列详情 / 条件编辑。
4. 点详情里的「去高德算」，会用深链在新标签打开高德的路线规划，由高德自己算真实通勤。
5. 所有关键步骤都有日志，出问题可以一键复制诊断信息发给开发者。

本版还没有的（下一步）
----------------------
- 通勤时长目前是「直线估算」，数字前带 ~。真实时长要等下一版从高德结果页读回。
- 地址搜索 / 新增目的地选点、自动发现小区、卫星影像与边界绘制。


安装步骤（Windows）
-------------------
1. 把压缩包解压到 D 盘根目录，得到：
      D:\xian-commute-ext\manifest.json
   （注意：文件夹里直接就是 manifest.json，不要再套一层目录）

2. 打开 Chrome 或 Edge，地址栏输入：
      chrome://extensions      （Edge 是 edge://extensions）

3. 打开右上角「开发者模式」开关。

4. 点「加载已解压的扩展程序」，选择 D:\xian-commute-ext 这个文件夹。

5. 打开（或刷新） https://www.amap.com/ ，页面右侧应出现侧边栏，
   左下角出现「西接通勤 · 已连接地图」。

   如果没出现：
   - 先刷新一次高德页面（扩展刚装好时旧页面不会自动注入）
   - 点右下角扩展图标 → 看「挂钩状态」
   - 还是不行：扩展图标 → 设置与诊断 → 点「复制诊断信息」，把内容发我


怎么用
------
- 右上角「编辑」可以改扩展现半径、每个目的地的通勤方式（驾车/公交/步行）。
- 点列表里的小区，面板变宽成两列：左边继续可选其他小区，右边是详情。
- 详情里每个目的地右边有「去高德算」，点开就是高德的真实路线页。
- 地图上的点可以直接点，按 Esc 收起详情。


数据在哪
--------
只存在浏览器的本地 IndexedDB（扩展自己的域），不上传任何服务器。
「设置与诊断」页可以导出全部数据、导出日志、重置样例数据。
